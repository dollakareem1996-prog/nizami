نظامي — خطوات التثبيت (مرة واحدة)

أ) الخادم في حسابكِ على Google
1. افتحي https://script.new وأنتِ مسجّلة بحسابكِ.
2. امسحي ما في المحرر والصقي محتوى الملف Code.gs كاملاً، ثم احفظي (Ctrl+S) وسمّي المشروع «نظامي».
3. Deploy ← New deployment ← اختاري النوع Web app.
   Execute as: Me — Who has access: Anyone ← Deploy.
4. وافقي على الصلاحيات (Advanced ← Go to نظامي ← Allow).
5. انسخي رابط Web app الذي ينتهي بـ /exec.

ب) نشر البرنامج على GitHub Pages
1. في GitHub أنشئي مستودعاً جديداً باسم nizami (Public).
2. Add file ← Upload files ← اسحبي كل ملفات هذا المجلد ← Commit.
3. Settings ← Pages ← Branch: main ← / (root) ← Save.
4. بعد دقيقة يصبح البرنامج على: https://dollakareem1996-prog.github.io/nizami/

ج) الربط والنقل (على الحاسوب)
1. افتحي رابط البرنامج ← ⚙ ← الصقي رابط /exec ← ربط.
2. سيظهر «رمز الربط» — احتفظي به للهاتف.
3. في «نقل بياناتي السابقة» اختاري nizami-migration.zip وانتظري حتى 100%.

د) التثبيت كبرنامج
- الحاسوب (Chrome أو Edge): أيقونة التثبيت في شريط العنوان ⊕ ← Install.
- أندرويد (Chrome): ⋮ ← Add to Home screen / Install app.
- آيفون (Safari): زر المشاركة ← Add to Home Screen.
- على الهاتف: ⚙ ← الصقي رابط /exec واكتبي رمز الربط ← ربط.

ملاحظات
- يعمل دون إنترنت، وتُزامن التعديلات تلقائياً عند عودة الاتصال.
- البيانات في جدول «نظامي - البيانات» والمستمسكات في مجلد «نظامي» على Drive، مع نسخة احتياطية يومية (آخر 30 يوماً).
- أقصى حجم للملف الواحد 25 م.ب.
